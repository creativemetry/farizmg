## To update text content
Open index.html and search for the text you want to change. Edit directly.

## To add your real images
Drop files into these exact paths:
- assets/images/mascot-hero.png
- assets/images/mascot-services.png
- assets/images/mascot-contact.png
- assets/images/photo-about.jpg
- assets/images/works/work-01.jpg → work-06.jpg
- assets/icons/c4d.png, redshift.png, blender.png, kling.png, runway.png, aftereffects.png, photoshop.png

## To update personal info
Search index.html for these 3 things and replace:
- "+62 812 3456 7890" → your real WhatsApp number
- "hello@metry.studio" → your real email
- "linkedin.com/in/metry" → your real LinkedIn URL

## To deploy updates after going live
git add .
git commit -m "update: describe what changed"
git push
(Vercel auto-deploys in ~30 seconds)
